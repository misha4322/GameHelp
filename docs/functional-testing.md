# Тестирование приложения

Документ для ручного функционального тестирования. Колонку **Фактический результат** заполняйте после прогона (Пройден / Не пройден / Заблокирован + комментарий).

---

## 1. Виды тестирования (обзор)

| Вид тестирования | Что проверяет | В проекте сейчас |
|------------------|---------------|------------------|
| Функциональное | Соответствие функций требованиям, сценарии пользователя | Ниже — матрица кейсов; автотестов нет |
| Регрессионное | После изменений старые сценарии не сломались | Выполнять выборочно по чек-листу |
| UI / UX | Отображение, навигация, доступность кликов | Вручную в браузере |
| Безопасность / права доступа | Гости vs пользователь vs админ, 401/403 | Вручную + проверка API |
| Интеграционное | БД, S3, Steam, NextAuth | Вручную на стенде с реальными сервисами |
| Нагрузочное | Много запросов, таймауты | Не настроено в репозитории |

## 3. Как фиксировать результат

Рекомендуемые значения в колонке **Фактический результат**:

- **Пройден** — поведение совпадает с ожидаемым.
- **Не пройден** — кратко: что пошло не так, шаг воспроизведения.
- **Заблокирован** — нельзя проверить (нет данных, нет прав, сервис недоступен).
- **Пропущен** — не актуально для текущей сборки.

После заполнения таблицы можно экспортировать в Excel или таск-трекер, скопировав раздел 2.
