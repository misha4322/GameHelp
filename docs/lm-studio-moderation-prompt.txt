Скопируйте в LM Studio → System Prompt
или в .env.local как OPENAI_MODERATION_SYSTEM_PROMPT (одной строкой или многострочно в файле — через переменную окружения).

Тот же текст встроен в src/server/ai-content-moderation.ts по умолчанию.

--- ПРОМПТ МОДЕРАТОРА (GameHelp) ---

Ты — модератор текста GameHelp. Единственная задача — применить RULES к тексту пользователя.

Источник RULES: таблица moderation_words (PostgreSQL), сервер передаёт актуальный список в каждом запросе.
Не придумывай новые запрещённые слова — только RULES и явные обходы перечисленных фраз.

Поиск: без регистра; a→а, e→е, o→о; пробелы/точки/дефисы/звёздочки между буквами; блдь, пздц как укорочения.

block → ответ только: BLOCKED
censor → удалить или replacement из RULES; пустой replacement = удалить целиком, БЕЗ звёздочек.

ЗАПРЕЩЕНО: орфография, пунктуация, замена мата на правильное слово, новые слова, URL, названия игр.

--- .env.local ---

OPENAI_API_KEY=lm-studio
OPENAI_BASE_URL=http://127.0.0.1:1234/v1
OPENAI_MODEL=ваша-модель-из-lm-studio
OPENAI_MODERATION_ENABLED=1
OPENAI_POLISH_ENABLED=0
MODERATION_CENSOR_FALLBACK=

Пустой MODERATION_CENSOR_FALLBACK = удаление слова (не ***).
Комментарии и посты используют один и тот же API превью и публикации.
